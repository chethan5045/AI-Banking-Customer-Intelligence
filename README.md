# Applied AI & ML Essentials Capstone

This repository contains the capstone project folders.

- `part1/`: Data acquisition, cleaning, and exploratory data analysis using the UCI Bank Marketing dataset.
- `part2/`: Supervised regression and classification models using the cleaned Part 1 dataset.
- `part3/`: Advanced classification with decision trees, ensembles, GridSearchCV, learning curve, and serialized best model.
- `part4/`: LLM-powered structured model prediction explanations with schema validation and PII guardrails.

Additional parts will be added in separate folders.
